# Imágenes de prueba

Suelta aquí las fotos (JPG, PNG o WebP) y avísame: yo las coloco donde van y las dejo optimizadas
(WebP, 1600 px de ancho máximo) en el bucket de Supabase Storage.

**Las fotos no se suben al repositorio.** Esta carpeta está ignorada a propósito: los originales
se quedan en tu máquina y al repositorio solo viaja este archivo con la instrucción.

## Nombres que ayudan

Si el nombre del archivo dice a dónde va, no hay dudas al colocarlas:

| Nombre | Dónde acaba |
| --- | --- |
| `galeria-1.jpg`, `galeria-2.jpg`… | Bloque de galería y reels |
| `polygel.jpg`, `rubber.jpg`… | Imagen de ese servicio del catálogo |
| `equipo-1.jpg`, `equipo-2.jpg`… | Bloque de equipo |
| `hero.jpg` | Imagen del hero (hoy Inicio no tiene ninguna) |

Si no los nombras así, tampoco pasa nada: dime qué es cada una y las coloco igual.

Cuando exista la subida desde el panel (Fase 2.5) esto dejará de hacer falta.
